📲 Cara Pasang Aplikasi

Aplikasi ini adalah PWA — satu kode untuk Android & PC. Setelah dipasang, ikon 🕌 muncul di layar utama / desktop.

Android (Chrome):
1. Buka aplikasi di Chrome
2. Ketuk ⋮ (menu tiga titik) → “Tambahkan ke layar utama”
3. Atau ketuk banner “Pasang” bila muncul
4. Konfirmasi → ikon muncul di layar utama
PC (Chrome/Edge):
1. Klik ikon install (monitor + panah ↓) di address bar
2. Atau menu ⋮ → “Install Sholat App”
3. Aplikasi terbuka sebagai jendela desktop
Notifikasi tetap saat aplikasi tertutup:
• Izin notifikasi & lokasi harus diizinkan
• Pada Android jangan “paksa tutup” (force stop) aplikasi
• Untuk pengingat walau tertutup penuh, aktifkan Push FCM (lihat pengaturan ini)
